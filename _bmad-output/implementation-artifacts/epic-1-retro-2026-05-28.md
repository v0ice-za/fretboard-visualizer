## Challenges & Patterns

### Pattern 1 — Architecture doc / repo mismatch
Architecture spec specified `main` as the deployment branch. Repo uses `master`. Story 1.9 implemented faithfully from spec and shipped a CI workflow that never fires. Fix: verify repo default branch against architecture doc before any story that references branch names.

### Pattern 2 — Deferred items compounding
40+ deferred items logged across the epic. Most are correctly deferred. One recurring item — `noteIndex -1` for unrecognised notes in `musicTheory.js` — appeared in Stories 1.3, 1.4, and remains open. This is a risk for Epic 2's chord library work (Story 2.4 calls `musicTheory.js` heavily).

### Pattern 3 — Debug artifacts left behind
`capo-check.js` and `capo-verify-1-initial.png` remain untracked in the repo root. Establish habit of cleaning up verification scripts before committing.
